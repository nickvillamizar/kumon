  TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

  ❌ Error: "module 'database.models' has no attribute 'X'"
     → Falta importar el modelo en alembic/env.py
     → Solución: Verificar que está importado en env.py

  ❌ Error: "database kumon_db does not exist"
     → Base de datos no creada
     → Solución: CREATE DATABASE kumon_db; en psql

  ❌ Error: "connection refused" al conectar a PostgreSQL
     → PostgreSQL no está corriendo
     → Solución: Iniciar servicio PostgreSQL

  ❌ Error: "ModuleNotFoundError: No module named 'fastapi'"
     → Dependencias no instaladas
     → Solución: pip install -r requirements.txt

  ❌ Error: "CORS error" en el navegador
     → Frontend no puede conectar al backend
     → Solución: Verificar que API_BASE en edupanel_FINAL.html es correcto

  ❌ El panel muestra datos vacíos
     → No hay datos en la BD o endpoint no responde
     → Solución: Verificar curl http://localhost:8000/api/v1/dashboard/stats
